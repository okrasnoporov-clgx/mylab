# 2. Проверка свободного места на дисках на обоих узлах

ansible all -m service -a "name=ssh state=started" -b

Static и Dynamic Inventory
Static Inventory — статический файл (или директория со статическими файлами), который вы ведёте сами (вручную или генерируете из CMDB/Terraform). Подходит для учебных стендов, небольших инфраструктур или фиксации известных узлов.
Dynamic Inventory — динамическое получение списка хостов и их метаданных в момент запуска Ansible из внешнего источника (AWS, Azure, GCP, VMware, Kubernetes, Docker, NetBox) через inventory-плагины (рекомендуемый современный способ) или исполняемые скрипты, возвращающие JSON определённой структуры.
