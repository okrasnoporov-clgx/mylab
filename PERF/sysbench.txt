Sysbench — это универсальная утилита командной строки 
для проведения нагрузочного тестирования (benchmarking) операционных систем, 
процессоров, оперативной памяти, дисковой подсистемы и баз данных.

Сколько операций в секунду способен выполнять процессор?
Какую пропускную способность обеспечивает оперативная память?
Какова скорость случайного чтения и записи на диске?
Сколько SQL-транзакций в секунду обрабатывает MySQL?
Как изменяется производительность при увеличении количества параллельных потоков?
Где находится предел производительности сервера?

Sysbench поддерживает несколько типов тестов (workloads).

CPU	cpu	Вычислительную производительность
Memory	memory	Скорость чтения и записи RAM
Disk I/O	fileio	Производительность файловой системы
Threads	threads	Производительность потоков и синхронизации
Mutex	mutex	Конкуренцию за блокировки
Database	oltp_read_write	Производительность транзакций БД

---------------------------------------------------------------------------------

sudo apt update
sudo apt install sysbench

sysbench --version
>>sysbench 1.0.20

Практически все тесты Sysbench запускаются по единой схеме:

1. Prepare
   
   Подготовка тестовых данных, если они необходимы.
   sysbench fileio prepare

2. Run
   
   Выполнение нагрузочного теста.
   sysbench fileio run

3. Cleanup
   
   Удаление временных тестовых данных.
   sysbench fileio cleanup

Не каждый тест требует всех трёх этапов. Например, CPU и Memory можно запускать непосредственно через run.

OLTP — это тип нагрузки, характерный для систем, которые постоянно выполняют небольшие транзакции:
- интернет-магазины;
- банковские системы;
- CRM;
- системы учёта;
- backend-приложения.
Sysbench умеет создавать тестовые таблицы в MySQL и выполнять над ними транзакции.

sysbench oltp_read_write \
  --db-driver=mysql \
  --mysql-host=127.0.0.1 \
  --mysql-port=3306 \
  --mysql-user=sbuser \
  --mysql-password=secret \
  --mysql-db=sbtest \
  --tables=10 \
  --table-size=100000 \
  prepare

sysbench oltp_read_write \
  --db-driver=mysql \
  --mysql-host=127.0.0.1 \
  --mysql-port=3306 \
  --mysql-user=sbuser \
  --mysql-password=secret \
  --mysql-db=sbtest \
  --tables=10 \
  --table-size=100000 \
  --threads=16 \
  --time=60 \
  --warmup-time=10 \
  --report-interval=5 \
  run

sysbench oltp_read_write \
  --db-driver=mysql \
  --mysql-host=127.0.0.1 \
  --mysql-user=sbuser \
  --mysql-password=secret \
  --mysql-db=sbtest \
  --tables=10 \
  cleanup

--------------------------------------------------------------------------------
Sysbench — синтетический benchmark. Его результаты не обязательно отражают поведение реального приложения.
CPU-тест не проверяет производительность всего приложения.
Memory-тест не заменяет полноценный анализ NUMA и пропускной способности памяти.
File I/O зависит от файловой системы, кеширования и настроек хранения.
OLTP-результаты зависят от конфигурации самой БД, индексов, размера данных и аппаратных ресурсов.
Для достоверного сравнения необходимо сохранять одинаковые условия экспериментов.
