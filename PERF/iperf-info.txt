iperf3 — один из основных инструментов для проверки производительности сетевых соединений.

Bandwidth	Пропускная способность, Mbit/s или Gbit/s
Throughput	Фактическая скорость передачи данных
Retransmissions	Повторные передачи TCP-сегментов
Jitter	Изменение задержки между UDP-пакетами
Packet loss	Потеря UDP-пакетов
TCP window	Размер окна TCP
Parallel streams	Производительность нескольких потоков одновременно

!!! не измеряет время выполнения SQL-запроса, скорость обработки HTTP-запроса или производительность CPU приложения.
